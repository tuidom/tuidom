# Input/

Слой движка TUIDom (монорепа пакетов `@tuidom/*`). Хост-приложение — [Diode](https://github.com/diode-editor/diode).

Пайплайн парсинга терминального ввода: сырые байты stdin → токены → `KeyPressEvent`. Включает токенизатор stdin, отслеживание мыши, stateful парсер клавиатурных событий (keydown/keypress/keyup в browser-like стиле) и обратную сериализацию для тестов.

## `code` — физическая клавиша, как в браузере

`KeyPressEvent.code` — клавиша US-раскладки, на которой нажат символ, независимо от активной раскладки: по нему хост матчит мнемоники (`MenuBarElement`) и кейбинды, когда `key` — не латиница (`Alt+а` в русской раскладке → `code: "KeyF"`).

- Kitty с флагом report alternate keys присылает base-layout key — `code` берётся из него, для любой раскладки.
- Легаси-ввод (tmux, терминалы без kitty, CSI u без base-layout key) несёт только символ: `inferCode` выводит `code` из латиницы, цифр, пунктуации и кириллической ЙЦУКЕН (русская, украинские і/ї/є/ґ, белорусская ў). Прочие символы — `code` равен самому символу.
