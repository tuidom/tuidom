# Генерация референса виджетов из кода

Пользовательская дока ([GUIDE.md](../../GUIDE.md)) намеренно НЕ описывает API
отдельных контролов — только обзорную таблицу элементов. Писать референс руками —
двойная поддержка: он разъедется с кодом при первом же рефакторинге.

План: референс по каждому виджету генерировать из исходников
(`packages/elements/src/**`, публичные части `packages/core/src/dom/**`) —
TSDoc-комментарии на классах и публичных членах + typedoc/api-extractor или
свой генератор поверх tsc API (решить при взятии в работу; учесть deep-imports
и `exports`-карту пакетов — типовые генераторы ждут единый entrypoint).

Критерий готовности: страница на виджет с конструктором, публичными
свойствами/методами/событиями и style-токенами, собираемая одной командой из CI;
раздел «Elements overview» в GUIDE.md ссылается на неё вместо этого файла.
