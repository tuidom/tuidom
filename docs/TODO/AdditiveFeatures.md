# Аддитивные фичи (проверено по коду, делается без слома)

Бэклог возможностей, добавляемых обычным порядком: новое поле с дефолтом =
старое поведение, контракты ядра не пересматриваются. Фильтр ведения файла:
**нестыковка** (модель противоречит себе или молчаливое решение вклеено в
сигнатуры так, что не сменить без слома клиентов) сюда не пишется — она чинится
через ADR в [LAYOUT.md](../LAYOUT.md)/[STYLES.md](../STYLES.md); сюда — только
то, что добавляется аддитивно.

- **Multi-fill с весами в HFlex/VFlex** — `width` уже размеченное объединение
  `fixed|fit|fill`; добавить `weight?` в вариант `fill` — правка внутри двух
  файлов.
- **`gap` во flex-контейнерах** — `{ gap: 0 }` по дефолту = сегодняшнее поведение.
- **Выравнивание по поперечной оси** — union `number | "fill"` расширяется
  вариантами `"start" | "center" | "end"`; обработать обязаны только сами
  flex-элементы.
- **`disabled`-флаг** — повторяет механику `hidden` (пропуск в Tab-обходе и
  хит-тесте); визуальная часть выражается состоянием стиля
  (`setStyleState("disabled")` + when-вариант, см. [STYLES.md](../STYLES.md)).
- **padding/border как обёртки** (`PaddingContainerElement`) — законная модель
  (так устроен Flutter); толщина рамки именована (`BORDER_THICKNESS`),
  формулы готовы к появлению модели отступов.
- **z-index** — числовой z-index не нужен: перекрытие решают порядок детей и
  слои (`OverlayLayer`); понадобится — вводится сортировкой в одном месте
  (рендер и хит-тест читают один список).
- **`list.hoverForeground`** — hover списков не меняет fg; токен добавляется
  аддитивно.
- **`notifyDetached` для hover** — сейчас hover «залипает» при detach
  hovered-поддерева до следующего mousemove (паритет с прежним поведением
  диспатчера); follow-up — уведомлять диспатчер мыши об отцеплении.
