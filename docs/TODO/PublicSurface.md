# Курируемая публичная поверхность и релизная гигиена

Сейчас (осознанно, см. дисклеймер в README): API нестабилен, semver-гарантий
нет, deep-imports открывают все внутренности (`exports: "./*"`). Это временное
состояние периода активной разработки; когда API устоится:

- **Курируемая публичная поверхность** — явные entrypoints (или явный список
  subpath-exports) вместо «всё наружу»; internals закрыть. Продумать миграцию
  потребителей deep-imports.
- **Semver-политика** — с какого момента обещаем semver, что считается breaking.
- **CHANGELOG** — вести с первого semver-релиза (или раньше, по желанию).
- **CONTRIBUTING** — как собирать/тестировать/публиковать (сейчас — AGENTS.md,
  он ориентирован на агентов, и на русском).
- **LICENSE-файлы в tgz** — в пакетах есть только `"license": "MIT"` в
  package.json, файла LICENSE в tgz нет (npm кладёт его только если файл лежит
  в директории пакета). Скопировать корневой LICENSE в пакеты при сборке.
- **Переименования под первое breaking-окно** — копить здесь; известное:
  опечатка в имени публичного модуля `@tuidom/core/common/geometryPromitives`
  (→ `geometryPrimitives`).

Критерий готовности: файл закрыт, когда объявлен первый semver-релиз с
курируемой поверхностью, CHANGELOG и CONTRIBUTING.
